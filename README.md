# Brevard County Foreclosure Dashboard

Real-time Brevard County foreclosure auction data.

## Data Sources
- Brevard County Clerk of Court (official)
- Updated daily at 6 AM EST

## Live Dashboard
https://brevard-foreclosures.pages.dev

## Automation
- GitHub Actions runs daily scraper
- Data stored in `/data` folder
- 87 active foreclosure cases

## Latest Update
Check `data/brevard_properties.json` for current data
